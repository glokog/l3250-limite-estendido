# Componentes e atribuições

Este pacote é uma distribuição não oficial dos ajustes de comprimento das Epson L3250 e L375.

O instalador `DriverOriginal.exe` é a cópia intacta de `L3250_L3251_X64_38005_LA.exe`, driver Epson **3.80.05.00**, com SHA-256:

```text
8cdb2c34bebc163578c0fcdaaf9c77e50b08184ef6c3d7b2038aab940df9c145
```

Para a L375, o instalador é a cópia intacta de `L375_X64_260_LA.exe`, driver Epson **2.60.00.00**, SHA-256 `1d121e1d46dd647303f985eabd563f3d2801273c9e1a4fbd0bbee74d193fd06c`.

Os pacotes completos incluem esses instaladores. A correção menor usa o driver compatível já instalado.

Os perfis CFX originais são arquivos do driver Epson; os perfis ajustados derivam desses arquivos e alteram atributos de comprimento e, na L3250 V7, regras de sem margem copiadas do perfil da L4260. O projeto não atribui nova licença aos arquivos Epson. Consulte os termos fornecidos pelo instalador original.

Epson e EcoTank são marcas de seus respectivos titulares. Este projeto não representa uma atualização oficial da Epson.

Os scripts PowerShell/C# e a documentação da aplicação do ajuste estão publicados para inspeção junto com os manifests e hashes. Nenhuma licença adicional foi escolhida nesta publicação.
